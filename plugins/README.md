# 现成的插件

可以直接用的 DeskPal 插件。用法：把文件复制到插件文件夹（Windows 是 `%APPDATA%\DeskPal\plugins\`），在 DeskPal「设置 → 插件」里点「刷新」并开启它。

| 文件 | 系统 | 作用 | 验证情况 |
| --- | --- | --- | --- |
| `windows-qq.ps1` | Windows | QQ 在前台时，显示当前会话名（好友或群） | QQ NT 9.9.37 主窗口 |
| `windows-wechat.ps1` | Windows | 微信在前台时，显示当前会话名（好友或群） | 微信 4.2.0.53 主窗口。单独弹出的聊天窗口未验证；旧版微信 3.x 不支持 |

两个插件都只提供「补充标题」（`detail`），放在插件列表的任何位置都可以，当前窗口、网站、暂离等仍由 Windows 内置插件提供。应用和分类不变：QQ、微信还是“在聊天”。想让某个群算工作，在首页「纠正分类」里按窗口标题设置。

它们怎么读：通过 Windows 的 UI Automation（系统的无障碍接口）只读会话顶部的名称这一个元素，不读消息内容，不注入，也不读软件的数据文件。软件改版后界面结构可能变化，读不到时插件什么都不报，DeskPal 显示原来的窗口标题。

补充的标题和普通窗口标题一样，受「不记录标题」和房间隐私设置控制，只有把“在聊天”设为显示详情的房间才能看到。

自己写插件见 [docs/provider-guide.md](../docs/provider-guide.md)。放进这个文件夹的 `.ps1` 要存成带 BOM 的 UTF-8，否则 Windows PowerShell 5.1 读错中文。
