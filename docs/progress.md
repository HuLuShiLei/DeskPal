# DeskPal 进度

新会话先读这份，了解哪些已经定了、做到了哪里。每次改了行为或做了决定，在最后的“变更日志”追加一条。

## 已定

| 主题 | 决定 | 原因 |
|---|---|---|
| 采集方式 | 不截图、不装钩子、不注入、不提权，只用普通用户权限的 API | 用户要求不截图；钩子和注入会被公司 EDR 当成键盘记录器 |
| 分类 | 个人分类优先，再用内置规则和推测。没有房间规则。只保留视频和游戏两类放松。音乐、购物、社交网站、新闻、阅读不再产生。用户不需要自己配置进程名和域名 | 用户要求只看当前焦点，并把网站类并进正在浏览网页 |
| 个人分类 | 「纠正分类」只改自己的识别结果，按账号保存在 Server，所有房间、所有电脑通用，不影响房间里的其他人（我的微信算工作，别人的微信仍是聊天）。识别结果照常广播，别人看到的是我自己的分类，例如“工作中 · 微信”；应用名是否显示仍按该房间的隐私设置 | 用户要求分类不影响他人、换房间不用重新设置，同时别人能看到我的分类 |
| 规则库改进 | 第一次打开面板时询问是否分享使用数据，设置里可以改。同意的用户上报未识别桌面应用的进程名、产品名和当天分钟数，个人分类也参与统计；不传窗口标题、网页和具体时间。注册满 3 天的账号才计票，一人一票，至少 5 人且 80% 一致才成为候选。每周由 GitHub Actions 生成 PR，人工审核后合并 | 用户要求规则库随使用自动完善、不纯靠人工；像游戏一样首次询问；候选走 PR 人工审核 |
| 窗口外观 | 不用系统标题栏，标题栏、最小化、关闭画在页面里，和应用风格一致；保留 Windows 11 圆角和阴影。颜色跟随系统浅色、深色模式，控件按 Windows 11 样式，页面不能选中文字、不显示手形光标 | 用户觉得原生标题栏难看，界面太像网页 |
| 关闭窗口 | 点关闭默认询问：最小化，或最小化到系统托盘，可勾选不再提示。设置「关闭窗口时」可选每次询问、最小化、最小化到系统托盘。退出仍在托盘菜单 | 用户要求点关闭时选择，文案按常见桌面软件 |
| 暂不显示 | 状态页不显示「房间成员看到」、手动状态和戳一下。手动状态和戳一下的命令仍保留 | 用户要求先收起 |
| 识别不出来 | 归为 `Other`，显示“正在使用 XX”，不算放松 | 宁可少报放松，不误报 |
| 麦克风 | 不采集，没有“会议中” | 麦克风被占用也可能是语音聊天或打游戏 |
| 聊天软件分类 | QQ、微信、Telegram 等个人聊天归为 `Communication`（在聊天）；企业微信、飞书、钉钉、邮箱、会议软件归为 `Work` | 用户选定 |
| 界面文案 | 书面用语：工作中、在聊天、正在浏览网页、正在使用 XX、在看视频、在玩游戏；不用“忙”“摸鱼”。本机识别分标题、应用、详情三行。页面上写「房间」，不写 Room | 用户要求 |
| 浏览器 | 前台是浏览器时显示“正在浏览网页”，后面是域名和页面标题，不按视频、社交、购物等细分。个人分类可以把某个网站改成其他类别。隐私设为“显示类别和应用”时 Room 成员看到域名；标题只在“显示详情”时发出 | 用户要求浏览网页不做细分 |
| Room 改名 | 只有所有者可以改，1 到 30 个字符 | 用户选定 |
| 界面技术 | 面板和登录页用 .NET 宿主 + 标准 WebView2 的 HTML 界面（Preact），托盘菜单保持原生；以后的桌宠用 WPF 原生透明窗口。见 [ui-tech-evaluation.md](ui-tech-evaluation.md) | AI 能在浏览器里看到和测试界面；透明窗口里的 WebView2 静止时也占 CPU |
| 面板 | 一个窗口三页：状态、房间、设置，用左侧导航切换，标题栏里切换房间。房间设置和应用设置分开。隐藏 5 分钟后释放 WebView2。更新的确认和提示显示在面板里 | 用户选定 |
| WebView2 Runtime | 安装包带 `--framework webview2`，安装时缺少就自动安装；启动时再检测一次，缺少时提示下载 | 少数 LTSC、精简版系统没有 |
| 隐私 | 按 Room、按类别配置；默认不发窗口标题。创建或加入房间时所有类别都写成“只显示状态”，要多显示由成员自己在该房间改；之前加入、没有保存过的房间仍按原来的默认值（工作、聊天只显示状态，其他显示类别和应用） | 同一个人在伴侣 Room 和同事 Room 可以显示不同程度；用户要求新房间默认只显示状态 |
| 通信 | Server 中转 + SignalR，不做 P2P；以后加端到端加密 | 公司网络打洞成功率低；多人 Room 和离线状态需要 Server；见 plan-v1 第八节 |
| Server 职责 | 只按 `Type` 和 `RoomId` 路由，不解析 Payload；实时状态只在内存里 | 给端到端加密留位置，少存数据 |
| 房间 | 可以加入多个房间，同一时间只进入一个。切换时给上一个房间发离线，房间仍留在列表里，再次进入不用邀请码。主动退出才会从列表移除，之后仍可用邀请码加入。人数上限来自 `MaxMembersPerRoom`，默认 20；已有房间在列出或有人加入时改成当前配置 | 用户要求先支持多人，并把人数上限从 8 配置成 50，之后改为 20 |
| 踢出 | 只有所有者可以踢出其他成员。被踢出的人从成员列表和自己的房间列表里消失，当前邀请码不能再次加入。邀请码换成新的之后可以重新加入。解散房间时这条记录一起删除 | 用户要求踢出后不能从列表里看到；邀请码更新后允许再加入 |
| Room 生命周期 | 参考 QQ 群：不自动删除；每人最多拥有 5 个 Room；邀请码 24 小时过期，重新生成后旧码失效；所有者要先转让才能退出；所有者可以解散 | 用户选定 |
| 技术栈 | .NET 10：WPF 托盘客户端，ASP.NET Core + EF Core + SQLite，JWT，Docker 镜像（GHCR）+ Portainer + 已有 Traefik | 用户指定 C#，有自己的服务器 |
| 检查更新反馈 | 手动点击后，设置页立即显示「正在检查更新…」，按钮变为「请稍候…」；下载过程显示「正在下载新版本 x（百分比）」。不使用 Windows 通知气泡。后台定时检查不显示这些过程，下载完成后设置页的「立即重启并更新」变为可用 | 用户要求点击和下载都要有反馈，并去掉检查更新的通知气泡 |
| 客户端更新 | Velopack。测试版通道 `beta`，正式版通道 `win`。安装测试版后默认继续接收测试版；正式版安装后要在设置里勾选「加入测试版」才接收。启动后和每 6 小时检查一次，后台下载。已下载的包只在退出或选择「立即重启并更新」时安装，启动时不自动安装。取消测试版会删除已下载的包。不强制重启。从测试版回到较低正式版时先询问。只保留最近 8 个测试版。Velopack 只读取最近 10 个 GitHub Release，要给正式版留位置。GitHub Release 说明附带更新内容，取提交标题：测试版相对上一次发布，正式版相对上一个正式版，最多 40 条 | 试用人员要尽快拿到修复；GitHub Release 单个文件小于 2 GiB，没有总容量和流量限制 |
| 发布 | 代码在 GitHub `HuLuShiLei/DeskPal`；推送默认分支自动构建 Server 镜像，并调用 Portainer Business Edition 的 webhook 拉取重建；客户端测试版在 main 改了客户端时自动发 Pre-release，正式版只在手动推送 `vX.Y.Z` 标签时发布。安装包文件名是 `DeskPal-<版本号>-Setup.exe`。对外地址 `https://deskpal.hafuhafu.cn:36443`，也是客户端默认地址 | 运营商封了 80/443，只能用 36443；3 节点以内的 Business Edition 许可证免费；试用期要小步更新；用户要求安装包文件名带版本号 |
| 安装目录 | 安装包是 Inno Setup 向导（`installer/DeskPal.iss`），用户选择安装目录，默认 `%LocalAppData%\Programs\DeskPal`，再次安装时默认上次的目录。向导内嵌 Velopack 的 Setup.exe，用 `--installto` 静默安装，只为当前用户安装。拒绝磁盘根目录、已有其他文件的目录和不可写的目录；换目录时提示旧目录不会自动删除。安装版的日志在 `<安装目录>\logs`，WebView2 缓存在 `<安装目录>\WebView2`；`settings.json` 和规则仍在 `%APPDATA%\DeskPal`。直接运行或安装目录不可写时，日志和缓存回到 `%APPDATA%\DeskPal\logs` 和 `%LOCALAPPDATA%\DeskPal\WebView2`。已装在 `%LocalAppData%\DeskPal` 的客户端更新后，旧日志留在 `%APPDATA%\DeskPal\logs`，不迁移。换目录安装时，指向旧目录的开机自启改到新目录 | 用户不想固定装在 AppData。Velopack 在同一目录重新安装或卸载都会清空整个安装目录，指向已有文件的目录时会删掉其中的文件；设置留在用户目录才不会丢登录状态 |
| Meeting | 不采集麦克风，不再产生。枚举成员保留，收到时显示为工作中。纠正和隐私设置不列出这一类 | 规则类别按整数保存，删掉中间成员会让后面的类别错位 |
| 问题与建议 | 设置页「反馈」提供入口，在系统浏览器打开 GitHub Issue 选择页（空白 Issue 已关闭，只能选「问题反馈」或「功能建议」） | 用户要求设置里可以跳去提交 Issue |
| 夜间模式 | 设置里可以选择跟随系统、浅色或深色。默认跟随系统，选择保存在本机设置 | 用户要求自己切换夜间模式 |
| 标题与程序名相同 | 界面上的详情和程序名去掉空白后相同（不区分大小写）时，不再把详情接在程序名后面。发出去的原始标题不变 | 用户开启显示标题后，窗口标题和程序名都是 QQ 时出现“QQ · QQ” |

## 已完成（第一期原型）

- Server：注册登录、Room 全部生命周期、隐私配置、个人分类、规则库候选统计、内置规则库（版本 3，190 条）、PresenceHub、Docker 部署文件、GitHub Actions（测试、客户端 exe、Server 镜像）。
- 客户端：5 个采集器、事件总线、分层分类、状态判断、防抖、隐私过滤、托盘和主窗口、登录、Room 菜单、戳一下、“这个判断不对”、手动状态、暂停分享、开机自启。
- 发布：GitHub Actions 三个任务（测试、客户端 exe、Server 镜像）都已跑通；Release `v0.1.0` 已发布；Traefik 主机上已新增 `/etc/traefik/conf/deskpal.yml`。
- 测试：109 个，全部通过。
- 第一批调整（[plan-2026-11-11-presence-ui.md](plan-2026-11-11-presence-ui.md)）：Room 改名、去掉麦克风、内置规则库版本 2、书面文案、本机识别分行显示。端到端自检过：改名广播、非所有者改名返回 403、对方卡片的长标题截断。
- 第二批调整（HTML 界面）：面板、登录页改为 WebView2 + Preact，删除 `MainWindow`、`MainViewModel`、`Views/Dialogs.cs` 和 CommunityToolkit.Mvvm。模拟数据下在浏览器里逐页检查过；真实客户端端到端检查过面板显示、“戳一下”、暂停分享、手动状态、改名，以及隐藏 5 分钟后释放 WebView2。
- 本机端到端验证过：模拟成员发送的状态在界面正确显示；对方收到本机状态（`Since` 正确）、“戳一下”的文字、暂停分享（立即生效）。
- 多人房间：人数上限默认 20；同一时间只向当前房间发布状态；所有者可以踢出。被踢出的人要用更新后的邀请码才能再加入。页面文案改为「房间」。
- 个人分类和自定义标题栏：模拟数据下在浏览器里逐页检查过浅色和深色。真实客户端端到端检查过：全新数据库依次应用三个迁移；首次打开时询问分享，同意后 Server 和本机都记为同意；标题栏拖动窗口、圆角边框；个人分类保存后只有本人的客户端收到 `rules.personalChanged` 并更新缓存，其他成员只收到状态；`Work` 设为显示类别和应用时，对方收到“工作中”和应用名。

## 还没验证

- 两台真实电脑之间联调，Server 部署到真实服务器。
- 浏览器域名（UI Automation）、媒体播放、锁屏这几个信号没有专门触发过。
- 纠正、隐私设置、转让、解散在模拟数据下点过，没有连真实 Server 点过。
- 没有 WebView2 Runtime 的系统上安装（要在第一次正式发布前用虚拟机装一次）。
- `rule-candidates.yml` 还没在 GitHub Actions 上跑过（脚本用本地样例试过新增、修改、跳过三种情况）；要先配置 secret 和 Stack 变量 `DESKPAL_MAINTAINER_TOKEN`。
- 「待归类」和使用数据上报要用一段时间才有数据，只在单元测试里覆盖。
- CI 下载 Inno Setup 6.7.3、编译安装向导、上传到 Release 这几步还没在 GitHub Actions 上跑过。本机已验证：全新安装、拒绝非空目录、运行中覆盖安装、Velopack 更新、换目录安装、卸载。
- Server 已通过 Portainer webhook 部署。从带 `revision` 的版本起，CI 会等到 `/health` 返回本次提交号。两台真实电脑登录还没验证。

## 偏离方案

| 方案 | 实际 | 原因 |
|---|---|---|
| 客户端一个项目 | 拆出 `DeskPal.Client.Core` | 纯逻辑可以在 net10.0 下单元测试 |
| `SetWinEventHook` 事件驱动 | 每秒轮询 `GetForegroundWindow` | 更简单，不依赖消息循环；开销可以忽略 |
| Windows Toast 通知 | 托盘气泡 | 少一个依赖；不需要注册 AppUserModelID |
| 麦克风占用算开会 | 不采集麦克风，不再产生 `Meeting`。枚举成员保留 | 麦克风被占用也可能是语音聊天或打游戏 |
| 内置规则按增量更新 | 版本号不同就全量下载 | 规则只有几百条，全量下载更简单 |
| 前置 Caddy 自动配置 HTTPS | 用已有的 Traefik（DNS challenge 泛域名证书），对外地址 `https://deskpal.hafuhafu.cn:36443` | 用户已有 Traefik；运营商封了 80/443 |
| 端口 | 本地开发用 5180 | 5284 被 QQ 占用 |
| 数据库目录 `data/` | `storage/` | Windows 不区分大小写，会和源码目录 `Data/` 冲突 |
