# 已知问题和限制

修掉一项就删掉，并在 [progress.md](progress.md) 记变更日志。

## 采集

- **浏览器域名不稳定**：UI Automation 依赖浏览器的界面结构，浏览器更新后可能失效；在地址栏上用 `FindFirst(Descendants)` 查找比较慢，所以加了 3 秒超时和“上一次没返回就跳过”。切换标签后最多约 2 秒才拿到新域名，这段时间仍显示上一个域名。彻底解决靠阶段 2 的浏览器扩展。
- 全屏判断按显示器边界，无边框窗口化的游戏可能识别不出来。

## 分类

- **第一次启动时没有缓存的内置规则**：要等 Server 返回以后才有内置规则，在这之前全部归为推测层或 `Other`。之后会使用本地缓存。

## 通信和账号

- “戳一下”在对方离线时直接丢失，没有离线消息。面板里离线成员的“戳一下”是禁用的，但对方刚掉线、面板还没刷新时仍可能发出。
- 没有 refresh token，token 30 天后过期，需要重新登录。
- 加入 Room 时的人数检查不在事务里，两个人同时用邀请码加入，可能超过人数上限。

## 工程

- Velopack 在同一目录重新安装或卸载时会清空整个安装目录，指向已有文件的目录时会删掉其中的文件。安装向导拒绝已有其他文件的目录，覆盖安装时保留 `logs\`；绕过向导直接运行 Velopack 的 Setup.exe 没有这层保护。
- 换到新目录安装后，旧目录不会自动删除，向导只提示用户手动删除。
- 中文语言包 `installer/ChineseSimplified.isl` 是 Inno Setup 的非官方翻译，取自 6.7.3。升级 CI 里的 Inno Setup 版本时要一起更新。
- 安装包没有代码签名。从浏览器下载后第一次运行会出现 SmartScreen 提示，公司的安全软件也可能拦截。之后的自动更新不经过浏览器，一般不会再出现这个提示。

## 界面

- 没有 WebView2 Runtime 的系统上还没有实测安装（Velopack 会先装运行时）。启动时检测到缺少只能提示下载，面板和登录页打不开。
- 前端的模拟宿主（`mockHost`）也打进了发布包。它只在没有 `chrome.webview` 时动态加载，客户端里不会执行，约 8 KB。
- 页面里的时间（“已持续 12 分钟”）由宿主每 30 秒重新推送一次，不是页面自己计时。
