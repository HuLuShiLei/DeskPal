# 已知问题和限制

修掉一项就删掉，并在 [progress.md](progress.md) 记变更日志。

## 采集

- **浏览器域名不稳定**：UI Automation 依赖浏览器的界面结构，浏览器更新后可能失效；在地址栏上用 `FindFirst(Descendants)` 查找比较慢，所以加了 3 秒超时和“上一次没返回就跳过”。切换标签后最多约 2 秒才拿到新域名，这段时间仍显示上一个域名。浏览器扩展已不在路线图里，这个限制会一直存在。
- 全屏判断按显示器边界，无边框窗口化的游戏可能识别不出来。

## 分类

- **第一次启动时没有缓存的内置规则**：要等 Server 返回以后才有内置规则，在这之前全部归为推测层或 `Other`。之后会使用本地缓存。
- **修改个人分类要连着 Server**：断网时「纠正分类」会失败，已有的个人分类仍从本机缓存生效。
- **规则库候选只看桌面应用**：浏览器网页不统计、不上报。内置的网站规则本来就不参与浏览器的默认分类，想改某个网站只能用个人分类。
- **未识别应用的时长只在内存里**：客户端当天重启后从 0 重新累计，下一次上报会把 Server 上该应用的分钟数改小。只影响 PR 里的分钟数，不影响人数。
- 规则库候选的门槛（5 人、80%、注册满 3 天）是初始值，没有数据依据。用户多了以后按 PR 的质量调整 `Rules__*`。

## 通信和账号

- 没有 refresh token，token 30 天后过期，需要重新登录。不再计划补上，上架 Steam 后改用 Steam 会话票据登录。
- 加入 Room 时的人数检查不在事务里，两个人同时用邀请码加入，可能超过人数上限。
- 0.1.2 之前的客户端没有注册邀请码输入框。Server 打开 `Auth:RequireSignupInvite` 后，用旧版本注册会失败，只显示通用错误（旧版本不认识新错误码）。登录不受影响，登录后会自动更新。
- 管理员名单只看 Server 配置，客户端在登录或调用 `/api/me` 时更新 `isAdmin`。改了名单要重启 Server，已登录的客户端下次启动才显示或隐藏设置页的「注册邀请码」；接口本身每次按当前配置判断。

## 使用统计

- **本人离线就看不到**：统计只在本人的电脑上，本人不在线、不在这个房间或客户端卡住时，请求 30 秒后提示失败。这是有意的取舍。
- **密钥交换没有身份验证**：请求方的临时公钥经过 Server 转发，没有和账号绑定。能控制 Server 的人可以替换公钥，以中间人方式读到统计。防的是 Server 日志和数据库，不防恶意的 Server 管理员。
- **数据可以伪造**：统计由本人的电脑计算，导入功能也能写入任意数据，只适合朋友之间看，不能作为考勤依据。
- **本机明文保存**：`usage\<userId>.db` 和导出文件里有窗口标题。同一 Windows 账号下运行的程序都能读到，文件被拷走等于浏览记录外泄。
- **换电脑**：单点登录后同一时间只有一台电脑在记录，另一台电脑上的记录要手动导出、导入才能合在一起。

## 工程

- Velopack 在同一目录重新安装或卸载时会清空整个安装目录，指向已有文件的目录时会删掉其中的文件。安装向导拒绝已有其他文件的目录，覆盖安装时保留 `logs\`；绕过向导直接运行 Velopack 的 Setup.exe 没有这层保护。
- 换到新目录安装后，旧目录不会自动删除，向导只提示用户手动删除。
- 中文语言包 `installer/ChineseSimplified.isl` 是 Inno Setup 的非官方翻译，取自 6.7.3。升级 CI 里的 Inno Setup 版本时要一起更新。
- 安装包没有代码签名。从浏览器下载后第一次运行会出现 SmartScreen 提示，公司的安全软件也可能拦截。之后的自动更新不经过浏览器，一般不会再出现这个提示。
- `PresenceHubTests` 的几个用例（屏蔽、改名通知、离线和退出）在整套测试并行运行时偶尔失败，单独运行稳定。原因是用 LongPolling 收消息时，等待某条消息的时机受机器负载影响。CI 上遇到时先重跑。

## 界面

- **旧版客户端看不到 Server 的错误说明**：Server 改为只返回错误码后，0.1.2-dev.26 及更早的客户端遇到接口错误时只显示「请求失败（HTTP 状态码）」，更新客户端后恢复。
- 内置规则库的英文名称按默认名称（中文）在接收方本机翻译。本机缓存的规则库还没有这个名称（第一次启动、规则库刚新增），或者名称来自个人分类、应用自己的产品名时，英文界面里仍显示原名。
- 没有 WebView2 Runtime 的系统上还没有实测安装（Velopack 会先装运行时）。启动时检测到缺少只能提示下载，面板和登录页打不开。
- 前端的模拟宿主（`mockHost`）也打进了发布包。它只在没有 `chrome.webview` 时动态加载，客户端里不会执行。加上使用统计的样例后约 80 KB。
- 页面里的时间（“已持续 12 分钟”）由宿主每 30 秒重新推送一次，不是页面自己计时。只有「n 秒后变为」的倒计时由页面每 250 毫秒自己刷新，宿主每次推送时重新对时。
- 标题栏拖动依赖 WebView2 的非客户区支持（`IsNonClientRegionSupportEnabled`）。WebView2 Runtime 太旧时标题栏拖不动，最小化和关闭按钮仍可用；Runtime 会随 Edge 自动更新，一般不会遇到。
- 窗口在 Windows 10 上没有圆角（DWM 圆角只在 Windows 11 生效），仍有边框和阴影。
